# Анализ предметной области: служба курьерской доставки (courier-service)

## 1. Организация

Служба курьерской доставки занимается приёмом, обработкой и доставкой отправлений от отправителей получателям. Организация принимает заказы на доставку через веб-приложение. Оператор регистрирует отправления, указывает адрес отправителя и получателя, а также назначает курьера. Курьер получает информацию о заказе и доставляет отправление по указанному адресу. Клиент может отслеживать текущее состояние своего отправления через систему.

### Проблемы текущего процесса

- Заказы регистрируются вручную, что увеличивает время обработки.
- Клиент не всегда может узнать текущее местонахождение отправления.
- Отсутствует единая система контроля работы курьеров и истории доставки.

## 2. Акторы

| Роль в системе | Кто это | Что делает в системе |
|---|---|---|
| admin | Администратор | Управляет пользователями и настройками системы |
| operator | Оператор службы доставки | Регистрирует заказы, оформляет отправления и назначает курьеров |
| courier | Курьер | Получает заказы, доставляет отправления и меняет статусы доставки |
| customer | Клиент | Создаёт заказ и отслеживает своё отправление |

## 3. Бизнес-процессы

| Процесс | Участники | Результат |
|---|---|---|
| Регистрация заказа | customer, operator | Создан новый заказ |
| Назначение курьера | operator, courier | Заказ назначен курьеру |
| Доставка отправления | courier, customer | Отправление доставлено |
| Отслеживание отправления | customer, operator | Клиент получает информацию о статусе отправления |

### 3.1. Оформление и доставка отправления

1. Клиент открывает веб-приложение и создаёт новый заказ.
2. Клиент указывает имя получателя, номер телефона и адрес доставки.
3. Система регистрирует заказ и присваивает ему уникальный трек-номер.
4. Оператор проверяет информацию о заказе.
5. Оператор назначает курьера для доставки.
6. Курьер принимает заказ и меняет статус на `accepted`.
7. Курьер забирает отправление и меняет статус на `in_transit`.
8. Курьер доставляет отправление получателю.
9. После подтверждения получения статус меняется на `delivered`.
10. Клиент может просмотреть историю изменения статусов отправления.

## 4. Объекты данных

| Объект | Основные сведения |
|---|---|
| Пользователь | ФИО, телефон, электронная почта, пароль, роль |
| Заказ | Номер заказа, дата создания, отправитель, получатель, статус |
| Отправление | Трек-номер, тип отправления, вес, описание |
| Курьер | ФИО, телефон, транспорт, статус работы |
| Адрес | Страна, город, улица, номер дома |
| История отслеживания | Отправление, статус, дата и время, местоположение |

## 5. Глоссарий

| Термин | Определение |
|---|---|
| Адрес доставки | Место, куда необходимо доставить отправление |
| Заказ | Заявка клиента на курьерскую доставку |
| Курьер | Сотрудник, который доставляет отправления |
| Отправитель | Человек, который отправляет посылку |
| Получатель | Человек, который получает посылку |
| Статус доставки | Текущее состояние отправления |
| Трек-номер | Уникальный номер для отслеживания отправления |
| Отслеживание | Просмотр информации о движении отправления |
