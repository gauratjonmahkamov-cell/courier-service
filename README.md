# Courier Service

## Название проекта
Веб-приложение службы курьерской доставки с отслеживанием отправлений.

## Тема проекта
Разработка веб-приложения службы курьерской доставки с системой отслеживания отправлений.

## Автор
Not1122

## Описание проекта
Данный проект предназначен для автоматизации работы курьерской службы. Система позволяет создавать заказы на доставку, регистрировать отправления, назначать курьеров и отслеживать статус доставки в режиме реального времени.

## Основные возможности
- Регистрация пользователей.
- Создание заказа на доставку.
- Назначение курьера.
- Отслеживание отправления.
- Изменение статуса доставки.
- Просмотр истории заказов..
